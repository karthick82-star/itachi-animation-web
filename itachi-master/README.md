# itachi-animation-web — TOJI FUSHIGURO: Cinematic Anime Experience

> **伏黒甚爾 — THE SORCERER KILLER**  
> An immersive, cinematic anime web experience dedicated to **Toji Fushiguro** from *Jujutsu Kaisen* (Hidden Inventory / Shibuya Incident arcs). Built with pure HTML5, CSS3, Vanilla JavaScript, Canvas API, and WebGL.

## 🗡️ Features & Architecture

### 1. Cinematic Scroll Scrub Canvas
- Interactive canvas presentation tracking scroll progression.
- Fluid transitions between Toji's tactical gun stance and his unleashed inventory curse combat aura.
- 4-stage narrative caption choreography:
  1. **天与呪縛 (Heavenly Restriction):** Zero cursed energy origin.
  2. **五感研磨 (Apex Physicality):** Supersonic reflexes and refined senses.
  3. **格納呪霊 (Inventory Curse):** Special grade cursed tool concealment.
  4. **術師殺し (The Sorcerer Killer):** Defeating the pinnacle of Jujutsu.

### 2. Live Target Acquisition & Parallax Combat Gaze
- Real-time mouse and touch-tracked 3D perspective projection.
- Tactical HUD telemetry with live coordinates and threat classification.
- Specular rim-lighting and glowing lens flares following cursor movement.

### 3. Classified Character Dossier
- Complete profile of Toji Fushiguro (Born Toji Zen'in).
- Technical combat breakdown: Heavenly Restriction, enhanced sensory perception, pragmatic warfare.
- Live animated stat bars for physical power, reaction time, and cursed tool mastery.

### 4. Cursed Weapons & Abilities (Interactive 6-Card Grid)
- **WebGL Ghost Cursor:** Ethereal purple cursed energy smoke shader that burns through shadows to reveal underlying art.
- **Inverted Spear of Heaven (天逆鉾):** Technique nullification jitte blade.
- **Split Soul Katana (釈魂刀):** Unblockable direct soul damage.
- **Playful Cloud (游雲):** Physical kinetic scaling three-section staff.
- **Chain of a Thousand Miles (万里ノ鎖):** Concealed infinite range chain.
- **Heavenly Restriction (天与呪縛):** Domain barrier immunity and undetectable stealth.
- **Exceptional Physical Strength (超絶身体能力):** Supersonic combat velocity.

### 5. Ambient FX & Web Audio Synthesizer
- **Cursed Hem Canvas:** Dual-pass procedural violet flame hem licking up from viewport bottom.
- **Floating Particles Canvas:** Drifting violet cursed energy embers reacting to scroll velocity.
- **Cursed Lightning Storm:** Recursive procedural lightning bolt generator with purple screen flash.
- **Synthesized Thunder Audio:** Pure Web Audio API procedural sound synthesis (biquad filters, noise burst, sub-bass oscillator) — no audio files needed!

## 🚀 Running Locally

Open `index.html` directly in any modern web browser or serve via any static web server:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
